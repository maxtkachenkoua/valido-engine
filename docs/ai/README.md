# Valido Engine AI Architecture Operating System

This documentation exists for AI developers working on Valido Engine.

Valido Engine is the platform. ValidoHub is one product built on top of that platform. Future AI sessions must never confuse those responsibilities.

Engine documentation explains architecture, boundaries, module responsibilities, and extension rules. Product behavior, browser plugins, product CSS, and tool UX belong outside Engine.

Start every Engine AI session with `START_HERE_AI.md`.
