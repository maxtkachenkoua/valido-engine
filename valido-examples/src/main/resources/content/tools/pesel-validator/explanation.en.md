PESEL is a Polish national identification number. A professional PESEL tool should validate length, digits, date encoding, checksum, and explain the derived birth date and gender.

The ValidoHub PESEL example is algorithm-backed through `validohub.pesel`. The implementation class is intentionally registry metadata only in Phase 1; generated artifacts and runtime behavior come later.
